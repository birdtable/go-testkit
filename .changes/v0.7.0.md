## v0.7.0 - 2026-11-26

One check is added to `canary`: `(*Set).Zip`, which reads each entry of a zip archive, its name and its bytes, so a support bundle a program writes is checked, with `CheckZip` beside it as its check's name. `canary` also closes three gaps: a line a check gives holds no run of 16 bytes or more of a planted value, where before only whole values and encodings were replaced; Files reads each link's target as text; and Own's doc gives how often its quarter rule refuses a random hex key. No name is removed or moved, and no signature changes: the API check finds no break since v0.6.0. Every name added is experimental, as every name of the module is. `canary` still imports the standard library only, `archive/zip` among it, and the root's go.mod still requires nothing. contain stays at contain/v0.1.3 and taskfile at taskfile/v0.1.2: nothing in either module has changed since v0.6.0, and since contain/v0.1.3 contain's api/systems.txt and api/marks.txt change in their comments alone. The tagged tree is 7,447 non-test Go lines outside `internal/` (`task size`), at its ceiling of 7,447, up 124 from v0.6.0's 7,323 (1.7%), all in `canary`, now 666: 62 for Zip, and 62 for the redaction of runs and the read of a link's target. The full release checks ran on macOS (arm64) at the tagged commit; vet and the tests, with the race detector, ran on Linux, macOS and Windows at the tagged commit in CI. No full release checks ran on Linux or Windows for this release.

### For a v0.6.0 caller

A test that passed at v0.6.0 can fail at v0.7.0 in two cases: Files now gives a hit for a link under the folder whose target's text holds a planted value, where it gave none, and still follows no link; and a link under the folder that it cannot read, as one removed after the walk, fails the test, as a file it cannot read already did. A line a check gives shows every run of 16 bytes or more of a value as <name>, where it showed a run that was no whole value or encoding. A test that wants a zip archive's entries checked calls Zip on it; Files still reads the archive as raw bytes. A test that draws its key at random each run and plants it with Own is refused by the quarter rule in about one run in 574, so it should plant a fixed value, or one New makes, as Own's doc now says.

### Added
* canary: `(*Set).Zip(path)` checks each entry of the zip archive at path, a support bundle among them: each entry's name, a hit there at `InPath`, as `Files` searches a path, and each entry's bytes, Stored or Deflate, through the same chunked read as `Reader`, so its memory is one chunk whatever an entry's size. A value in a folder of an entry's name is a hit at each entry under it, where `Files` counts it once, at the folder. A hit's place is the archive's path, `!` and the entry's name, each value in it as `<name>`, with `CheckZip` as its check, the byte offset in the entry and the encoding. A corrupt archive, one `archive/zip` cannot open, and an entry it cannot read, a checksum that does not match or a compression method it does not know among them, fail the test. It does not open a zip archive inside an entry, which it reads as that entry's bytes, nor read an encrypted entry's bytes, whose name it reads, nor read any other archive format: tar, gzip and 7z files are raw bytes to `Files`, as they were. `Files` is unchanged: it still reads a zip archive as raw bytes, and its doc points to `Zip`.

### Fixed
* canary: a line a check gives holds no run of 16 bytes or more of a planted value or of any of its encodings, where before only whole values and encodings were replaced by the value's name. A place where one value runs on into another, the first ending as the second starts, is now shown as <a><b>, where 17 bytes of the second stayed in the line; and a file whose name starts with 24 bytes of a value is shown with those bytes as <name>.
* canary: Files reads the target of each symbolic link under the folder as text, the place "<path> (target)", so a program that points a link at a planted value, as with os.Symlink(token, "current"), is caught. It still follows no link: it reads the link, not what the target names. Own's doc says a value drawn at random each run can fall to its quarter rule, one digit over a quarter of 32 random hex characters in about one draw in 574, and that a test should plant a fixed value or one New makes.
