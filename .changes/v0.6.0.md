## v0.6.0 - 2026-11-26

One package is added to the root module: `canary`, which plants fake secrets and checks that none reached a file, a stream or a returned value. `cmd/apigate`, the API gate, gains `-before-head` and reads a module in a folder that requires the root through a workspace of its own. No name is removed or moved, and no signature changes: the API check finds no break since v0.5.0. Every name added is experimental, as every name of the module is. `canary` imports the standard library only, as the root does, and the root's go.mod still requires nothing. contain stays at contain/v0.1.3 and taskfile at taskfile/v0.1.2: nothing in either module's code has changed since those tags, and contain's api/systems.txt and api/marks.txt change in their comments alone. The tagged tree is 7,315 non-test Go lines outside `internal/` (`task size`), at its ceiling of 7,315, up 711 from v0.5.0's 6,604, all in the root: 534 for `canary`, and 177 in `cmd/apigate`, 81 for `-before-head`, 85 for the base's workspace and 11 for reading its go.mod files with no lint directive. The full release checks ran on macOS (arm64) at the tagged commit; vet and the tests, with the race detector, ran on Linux, macOS and Windows at the tagged commit in CI. No full release checks ran on Linux or Windows for this release.

### For a v0.5.0 caller

Nothing changes for a test: every name gives what it gave. A test that hands a secret to the program under test can plant a fake one with `canary` and check the folders, streams and values the program wrote. A module that runs `cmd/apigate` from a folder whose go.mod requires the repository's root no longer needs a workspace script of its own for the base; the head is read through the workspace the caller's `GOWORK` names, as before. A gate that runs at its own tag can pass `-before-head` to hold the breaks since the tag before.

### Added
* canary: a test plants fake secrets with New, or a value of its own with Own, hands them to the program under test, and checks with Files, Reader, Bytes and Value that none reached a file under a folder (a SQLite file and its -wal and -journal read as raw bytes, with no driver), a captured stream or the text of a returned value. Each value is looked for as it is, as hex in both cases, as base64 and URL-safe base64 at each of the three alignments, as percent-encoding (a URL query or path escape) and as UTF-16 in both byte orders. Files also searches the path of each file, folder and link below the folder: a value in a name is a hit at InPath. A hit fails the test naming the value's name, the check, the place, the byte offset and the encoding, and canary never prints a value: every line that names a place or an error holding one, a path among them, shows it as <name>. Files follows no link and reads no FIFO, socket or device, a file it cannot read fails the test, and a check on a Set with no value planted stops the test. Its limits: a value compressed or encrypted (gzip, a zip archive), or written in an encoding the list does not name, base32 among them, is not seen; a value split across a SQLite overflow page boundary is not found, as SQLite moves the tail of a long record onto overflow pages with a 4-byte page number in between; and process memory, the network and any file outside the folders a test names are not checked. canary is 534 non-test Go lines, and the size ceiling rises by 534.
* cmd/apigate: given -before-head, the API check at a tagged head compares against the newest earlier tag: check 2's base is the newest tag that is an ancestor of the head and does not point at it, so the run at v0.2.0 holds the breaks since v0.1.0, and a head whose only tags are its own holds no break, as with no tag. The flag is off by default, and without it the check reads as before, from the newest tag on or below the head.

### Changed
* cmd/apigate: check 2 reads a module in a folder whose go.mod at the base requires the repository's root through a workspace of the base's own, written from the base's go.mod files: the base's root and the module, the root at the version the module requires replaced by the base's root. It takes no flag. contain's task contain-api runs cmd/apigate through CONTAIN_WORK's workspace, and gate/api.sh is gone.
