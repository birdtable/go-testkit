## v0.3.0 - 2026-11-22
### Added
* `Interrupted(ctx)` gives a child of `RerunInterrupted` a context that ends at the interrupt, and its stop. It installs the handler and only then writes `Ready`'s line, so the parent's interrupt never comes before the handler and ends the child by the default action. Outside a child of `Rerun` it returns `ctx` and a stop that does nothing, installs no handler and writes nothing. Its error is `Ready`'s, and then it leaves no handler. `Ready` stays for a child that catches more than the interrupt.
### Fixed
* `cmd/apigate` refuses a name `api/marks.txt` lists whose `go doc` prints a line holding `Experimental`, and names the `api/marks.txt` line and that doc line. Listing a name marks it as not experimental, so the doc and the list disagreed, and v0.2.0's gate passed it.

### Known limitations
* Added 2026-11-22, after the tag: on macOS the temp folder `Main` and `Isolate` make, and so `t.TempDir`, `os.TempDir`, `TMPDIR`, `HOME`, `HoldRead`'s path and `Binary.Path`, sits behind the `/var` -> `/private/var` link and is named as made, under `/var/folders`, while a path read back by `filepath.EvalSymlinks` or `os.Getwd` is under `/private/var/folders`; `ShortDir`'s `/tmp` reads back as `/private/tmp` the same way. The two spellings differ as strings, so a test that compares a path it was given with one read back resolves its own with `filepath.EvalSymlinks` first. Neither v0.2.0's notes nor v0.3.0's said so. The kit keeps answering the spelling Go's `t.TempDir` and `os.MkdirTemp` give, and each of those calls' docs now says which spelling it answers.
